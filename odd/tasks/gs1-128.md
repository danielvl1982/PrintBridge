# GS1-128 (the GS1 standard identifier for logistic units)

Status: PLANNED (added 2026-10-09 at the user's request; not started). Reference named by the user: "GS1-128, GS1 Spain: the standard
identifier for logistic units". Branch when started: `feat/gs1-128`. Create the Engram mirror `odd/gs1-128/tasks` before the first write.

## Objective
Support GS1-128 labels in the three languages: a Code 128 symbol that starts with FNC1 and carries GS1 Application Identifiers (AI),
e.g. `(00)` SSCC, `(01)` GTIN, `(10)` lot, `(17)` expiry, `(21)` serial, `(37)` count, `(400)` order number; read, drawn, edited, written
and converted between TPCL, TSPL and ZPL.

## What GS1-128 needs (to verify against the GS1 General Specifications and the printer manuals before designing)
- Data entered as AI element strings with parentheses `(01)09501101530003(17)250101(10)ABC123`; the symbol encodes the AIs without the
  parentheses; the human readable line keeps them.
- FNC1 as the first symbol character after the start character (what makes it GS1-128 instead of plain Code 128), and FNC1 as the separator
  after a variable-length AI (the last element does not need one). The model already has an FNC1 character (`PB.barcodeData.FNC1` in
  js/core/model.js; TPCL writes it as `>8`).
- Fixed-length AIs table (so the separator is only written after variable-length AIs) and the check digit rules (GTIN-8/12/13/14 and SSCC
  mod 10, the check digit being part of the data).
- Code 128 subset switching to numeric pairs (code set C) is what the existing Code 128 encoder already does; confirm it handles FNC1 in
  set C and the mid-symbol FNC1.

## What the manuals say the printers support (found by a keyword search, to be read in detail)
- TPCL: `XB` type `N` is listed as `UCC/EAN128` in B-SV4 (2004) and B-452-R (2012), with its check options ("UCC/EAN128 Modulus 10 +
  Modulus 103"). The app does not draw it today.
- TSPL: `BARCODE ... "EAN128"` (already read as Code 128 per the README, with the content kept).
- ZPL: `^BC` with mode `U` (UCC case mode) / `D` (UCC/EAN mode, later guides) and the `>8` FNC1 start code; the README says `e` (UCC check digit) and
  `m` are read, kept and not applied.
